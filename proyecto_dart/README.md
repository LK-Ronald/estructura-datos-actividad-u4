# Proyecto de gestion de eventos

Aplicacion de consola en Dart para gestionar eventos, jornadas, actividades,
subactividades, responsables y participantes mediante un grafo dirigido.

## Ejecutar

Desde esta carpeta:

```shell
dart run
```

La aplicacion inicia con el grafo vacio. Usa la opcion `7` para agregar
entidades y la opcion `15` para conectarlas. El menu incluye recorridos DFS y
BFS, consultas de conexiones y estadisticas.
